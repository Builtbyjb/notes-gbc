## Week 2 - Bits and Bytes
- Morse code was invented in the 1840s by Samuel Morse
- 1 byte is 8 bits 
- Computer systems have tow main types of memory; volatile and non-volatile

## Week 3
- A computer knows where a line ends by using special characters embedded in the byte sequence
- Serialization is the process of converting data structures (like objects or tables in memory) into a format (like JSON or XML text) that can be stored or transmitted.
- To display a character that has a special meaning in markup lanaguages, you need to **escape** the special character

## Week 4
- Aspects of a keyboard layout; physical layout, visual labeling, functional layout
- Modifier keys do not producte a character on their own but change the function of other keys when pressed simultaneously
- Wildcars are simple pattern-matching characters, which matches any sequence of characters including none. An example of a wildcard character is *

## Week 5
- Command Line Interfaces (CLI) are a way of interacting with a computer by typing text commands.
- A ~ symbol is a common shorthand for the user's home directory
- SSH (Secure Shell) provides an encrypted connection between your computer and a remote server, ensuring privacy for your commmunication
